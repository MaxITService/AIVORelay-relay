How Recovery Works

The extension tries saved selectors, then defaults, then heuristics. If that still fails, it can offer a manual picker toast so you click the right element once and save it.
Editor is the text input. Send button submits the prompt. Stop button is checked first so AivoRelay does not send while the AI is still generating. If a site falsely looks "busy", you can ignore stop detection below.
If text never appears, fix Editor. If text appears but does not send, fix Send button. If AivoRelay sends too early while the AI is still answering, fix Stop button.
Manual picker: Pick Element only chooses an element on the page. Save for This Site is the step that actually stores it.
